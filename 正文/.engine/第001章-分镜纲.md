# 第001章分镜纲：这件裙子是怎么回事

## 元信息
- 章节号：第001章
- 目标字数：4500 ± 500
- 建议场景数：3

## 本章输入摘要
- **子大纲目标**：建立陈逸日常人设；引出妹妹的同人事业；让读者在轻松搞笑中产生好感
- **上一章结尾承接**：首章，无承接
- **本章必须回应的问题**：为什么要女装？为什么能女装得不像男扮女装？
- **本章必须制造的新问题**：这个叫程昱月的女人是谁？她要做什么？

## 场景清单（共3场）

### 场景1（建议占比 25%）
- **场景目的**：建立陈逸的日常——宅男、轻度社交回避、暗恋林小羽但完全不会表达
- **时间/地点**：清晨 → 午休，大学教室
- **出场角色**：陈逸、林小羽、同学A/B
- **冲突/阻力**：陈逸想跟林小羽说话但找不到自然的方式，每次开口都卡在"早上好"之后
- **场景动作链**：趴在桌上装睡（实际在看林小羽侧脸）→ 被同学A拉进话题 → 林小羽主动搭话 → 陈逸回答僵硬 → 妹妹发来消息"放学来我社团教室"→ 成功制造逃避借口
- **感官锚点**：教室窗外透进来的晨光、林小羽翻书时纸张的声响、手机震动打断对话的触感
- **对话任务**：林小羽的对话展示她温柔但略强势的性格；陈逸的卡壳展示他的沟通缺陷
- **信息投放**：展示陈逸对林小羽的单恋 + 他"不会说话"的人设 + 妹妹的存在
- **伏笔操作**：F001（林小羽初中名言——通过陈逸走神时的回忆闪回半句植入，不完整，制造悬念）
- **结尾钩子**：妹妹的消息结尾加了一个兔子表情——"有好东西给你看 :) —— 这条消息让陈逸背脊发凉，因为上次收到这个表情，他被迫吃了一整碗妹妹做的"新研发"咖喱"

### 场景2（建议占比 35%）
- **场景目的**：骗穿女装的喜剧核心——场景以搞笑为主，同时展示妹妹的专业度与程昱月的"猎人"登场
- **时间/地点**：放学后，美术社团教室
- **出场角色**：陈逸、陈晓晓（妹妹）、程昱月（首次登场）
- **冲突/阻力**：陈逸以为妹妹找他当模特是画速写，结果是要他"穿上这件连衣裙站10分钟"；发现时已经被反锁在更衣间里
- **场景动作链**：推门进社团教室 → 看到人台模特上的裙子感觉不对 → 妹妹一脸天真说"帮我试一下嘛" → 被推进更衣间 → 听到门锁咔嗒声 → 挣扎五分钟后穿着裙子出来 → 妹妹调整肩带和假发 → 门突然被推开 → 程昱月进来 → 沉默 → "这个人在哪找到的？"
- **感官锚点**：连衣裙布料接触皮肤的凉意、假发摩擦颈侧的痒感、高跟鞋让站姿变形的陌生重心
- **对话任务**：妹妹用过往"债务"挨个施压（搞笑）；程昱月的问话短、精准、压迫感
- **信息投放**：妹妹是BL同人画手，在校有独立社团教室；程昱月不是偶然出现，她专程来看"模特"
- **伏笔操作**：F007（童年女装经历——通过陈逸被妹妹威胁"你小时候又不是没穿过"来提及）
- **结尾钩子**：程昱月站在门口看陈逸的眼神——不是惊艳，不是好笑——是"找到了"的确认

### 场景3（建议占比 40%）
- **场景目的**：从喜剧转向悬疑——程昱月的名片与"镜"的剪影，给首章留下强钩子
- **时间/地点**：社团教室门外走廊 → 回家路上
- **出场角色**：陈逸、程昱月、陈晓晓
- **冲突/阻力**：陈逸换回男装后想赶快走，被程昱月叫住；她递出名片却不解释具体合作内容，只说"下次请务必来一趟"
- **场景动作链**：陈逸换好衣服推门出来 → 程昱月靠在走廊墙上等 → "五分钟就好" → 陈逸被迫跟着走到楼梯间 → 程昱月给他看手机上的角色设定图 → 陈逸认出那是妹妹画稿里的角色 → "这是你妹妹的作品，但我想请你来演她" → 陈逸混乱中拒绝 → 程昱月把名片塞进他手里 → "你会联系我的" → 转身离开
- **感官锚点**：傍晚走廊斜射的阳光、程昱月手机屏幕亮度在暗处刺眼
- **对话任务**：程昱月说话节奏——先用日常语速降低防备，在关键句上放慢语气制造压迫感
- **信息投放**：妹妹画稿里的剪影角色 = 程昱月手机里的角色 = "镜"的原型；这个企划已经存在一段时间了
- **伏笔操作**：F003（通过程昱月提及"我上一个企划没做成"埋下） + F006（手机快速闪过一个全息系统界面，陈逸没看清）
- **结尾钩子**：（双重钩子）
  1. 陈逸回到家，名片放在桌上，他盯着上面"Glass Studio"的字样发呆。手机震动——妹妹发来消息："对了哥，程姐说的事你考虑一下吧，我觉得你超适合的 :)"
  2. 与此同时，林小羽在LINE上发来消息："今天早上你想跟我说什么？看你憋了一整天 :)"

## 章节描写规约（硬约束）
- 前20%出现冲突：陈逸暗恋不敢开口的内向冲突 + 妹妹的威胁消息
- 每个场景至少1个可视动作：场景1的"假装看手机实则偷瞄"、场景2的"被推进更衣间"、场景3的"名片被塞进手心"
