# 总大纲：《镜中的她》

## 作品信息
- **书名**：《镜中的她》（暂定）
- **类型**：校园恋爱喜剧 / 伪娘 / 宅系 / 轻度悬疑
- **题材关键词**：女装中之人、虚拟偶像、全息直播、双面生活、身份错位
- **目标读者**：轻小说受众、宅向读者、喜欢身份错位喜剧+真挚感情线的群体
- **预计总章数**：60 章（三幕各 20 章）

## 核心卖点
1. **双面身份的爆笑与紧张并存**：男主白天是普通宅男同学，晚上是全校追捧的虚拟美少女偶像，两边的社交圈不断逼近碰撞线。
2. **"中之人"专业性描写**：结合真实 VTuber/虚拟偶像行业运作细节（动捕、运营、粉丝运营），给读者"行业内幕"的满足感。
3. **三重感情线的交错张力**：男主对青梅竹马的单恋、虚拟形象与榜一大哥的暧昧、合作女搭档发现真相后的化学反应——每条线都"不能说"。

## 主线冲突
- **主角核心诉求**：保护妹妹的梦想不被毁掉 + 维持正常校园生活 + 不暴露身份
- **外部阻力**：
  - 企划公司要求持续曝光，校内追星族越来越多
  - 同班同学/学生会开始调查"镜"的真实身份
  - 竞争对手公司想挖出中之人进行抹黑
- **内部阻力**：
  - 男主对女装身份的抗拒→接受→依赖的自我认知矛盾
  - 虚拟身份获得的认可与真实自我的落差
  - 对青梅竹马的感情因身份分裂而说不出口
- **失败代价**：妹妹的企划被毁、家族声誉受损、自己在学校社死、失去所有朋友

## 剧情结构

### 第一阶段：误入镜中（第1-20章）
- **起始状态**：陈逸（19岁）——重度宅男、轻度社交回避、暗恋青梅竹马林小羽但从未说出口。缺点是说话直、容易慌张，优点是游戏策略分析极强（曾是校电竞社核心），观察力敏锐。
- **引爆事件**：妹妹陈晓晓的BL同人志需要"女性体态模特"，陈逸被抓去当人肉衣架。试穿女装后被妹妹的大学同学——正在孵化虚拟偶像企划的制作人——一眼相中。
- **阶段目标**：陈逸被迫签约成为虚拟偶像"镜"的中之人，承诺"只做三个月，等找到替代者就退"。
- **阶段结尾悬念**：虚拟偶像首播爆红后的第二天，陈逸发现班上新来的转学生——就是前天刚跟自己签合同的制作人。他盯上了陈逸，眼神分明在说"我知道你是谁"。

### 第二阶段：镜的两面（第21-40章）
- **局势升级**：
  - "镜"的人气从校园扩散到全市，线下活动邀约不断
  - 学生会成立"镜的真相调查委员会"（副会长正是林小羽）
  - 竞争对手公司开始用技术手段追踪中之人的动作习惯特征
- **核心反转**：陈逸发现自己越来越依赖"镜"的身份——那个在镜头前从容、自信、被千万人喜爱的女孩，比真实的自己更像"理想的自己"。他开始恐惧三个月后"杀死镜"的那天。
- **阶段目标**：在季度大型演唱会"Mirror Stage"上完成最终演出，同时应对学生会调查逼近临界点。
- **阶段结尾悬念**：演唱会最高潮时，全息投影出现故障，"镜"的真实轮廓（穿着动捕服的陈逸）短暂显现在舞台侧幕的大屏上——有人拍下了照片。

### 第三阶段：打破镜面（第41-60章）
- **最终冲突**：
  - 照片在网上疯传，"镜是男的吧"登上热搜
  - 学园祭上学生会安排了"镜的中之人揭晓"环节，林小羽作为副会长必须执行
  - 竞争对手公司的人混入准备现场，打算全球直播揭面瞬间
- **核心牺牲或代价**：陈逸在学园祭的讲台上，当着全校面脱下了假发——不是为了被原谅，而是为了在"镜"被他人揭穿之前，用自己的话给出答案。
- **胜负结果**：
  - "镜"的企划没有毁灭——对真相的诚恳回应反而让粉丝群体分化但核心层留下
  - 林小羽说了句"我喜欢的本来就不是镜"——指向不明
  - 妹妹的企划升级为正式商业运作
- **主题兑现**：不需要成为"完美的他人"也值得被喜欢。**伪装的尽头不是真面目，而是接受真面目的勇气。**

## 角色设定摘要

### 陈逸（男主 / "镜"的中之人）
- 19岁，大一生，轻度社交回避
- 特长：游戏策略分析、观察力敏锐、处于危机时反而冷静
- 缺陷：日常沟通能力差、不敢表达真实情感、对认可上瘾
- 人物弧线：从"躲在角色背后"到"用自己的脸说话"

### 林小羽（青梅竹马 / 学生会副会长）
- 19岁，与陈逸同校，品学兼优
- 表面温柔可亲，骨子里有极强的正义感与好奇心
- 对"镜"有特殊的好感，同时因为调查任务陷入心理矛盾
- 人物弧线：从"按规则行事"到"按自己的判断行事"

### 陈晓晓（妹妹 / 同人漫画家 / 企划原案）
- 17岁，高三，BL同人圈小有名气
- 最早察觉哥哥女装有潜力的人
- 对哥哥有复杂的"亲情+愧疚+自豪"情感

### 程昱月（制作人 / 转学生）
- 19岁，大一经管系转学生
- 外表是冷静的眼镜美少女，内在是疯狂的项目推进器
- 隐藏着"上一个企划失败"的心理创伤
- 与陈逸形成"我知道你的秘密/你不知道我的秘密"的不对称关系

## 结尾与续作钩子
- **本作闭环**：身份公开、感情线落定、企划迎来新形态
- **可延展支线**：
  - 程昱月的上一个企划真相（外传/前传）
  - "镜"的品牌独立化后的商业对手线
  - 林小羽视角的"其实我早就知道了"回顾篇
  - 其他虚拟偶像企划的行业竞争篇
